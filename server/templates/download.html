  • Reads the signed-in Steam user's own profile

  • Does not need administrator rights

Run it

  1. Open Steam and sign in.The game can stay closed.
  2. Run BattleBitStatRipper.exe.Windows may show a SmartScreen prompt for an unsigned app.
  3. Press Rip stats.The file lands in Documents\BattleBit Stats Ripper.
  4. Upload the .bbrstats file here.It attaches to your account.

If it stops

Steam not running
Start Steam, then retry.
Ticket refused
Sign out and back into Steam, then retry.
Schema changed
The app keeps the raw response and reports a decode warning.
Anything else
Copy the error code and open the diagnostics file from the app.

Every run writes %LOCALAPPDATA%\BBR Stats Ripper\logs and a diagnostics report.
